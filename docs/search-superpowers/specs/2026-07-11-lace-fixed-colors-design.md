# J 鞋带固定色值材质设计

## 目标

将 `J` 部件（鞋带）的材质选择收敛为 5 个固定色值，不再允许选择官方皮料分类或皮料纹理：

1. 黑色 `#000000`
2. 白色 `#ffffff`
3. 红色 `#e41c16`
4. 土黄色 `#e2bc00`
5. 紫色 `#380059`

其它部件的材质选择保持现状。鞋带默认仍显示当前的白色效果。

## 方案

采用共享 schema 约束 + C 端渲染适配：

- 在 `shared/yjs-pro-cim-schema.js` 为 `J` 增加固定色值选项，使用 `fixedStyleSet.colorOptions` 表达名称、英文名称和色值，并将部件材质入口收敛为 `fixed-image`。
- 在 `shared/schema-utils.js` 中优先识别带 `colorOptions` 的固定色值部件，使其不会从 `materialAvailability` 推导出官方皮料分类。
- 在 `app.js` 中补齐固定色值部件的默认配置、材质入口显示、颜色选择和导出名称处理。颜色按钮直接更新 `color`，鞋带继续沿用现有 mask tint 渲染路径。
- 在现有材质契约测试中增加 `J` 的固定色值约束，至少验证完整色值集合、顺序、默认白色和唯一 `fixed-image` 材质入口。

不采用仅在 `app.js` 对 `J` 做特判的方案，因为那会让共享 schema 和 B 端配置继续暴露全部官方皮料，导致数据契约与 C 端界面不一致。

## 数据与交互

初始化时，`J` 的 `color` 从 `defaultStyle.color` 读取并匹配固定选项，默认匹配白色；`material` 固定为 `fixed-image`。打开 `J 鞋带` 后，材质区域只展示一个固定样式入口及其 5 个颜色按钮，不展示皮料分类和纹理子项。

点击任一颜色后，更新 `J.color`，保持其它配置不变，重新渲染鞋带 mask；导出配置中的颜色名称和值反映所选固定色值，材质名称保持为固定样式。

## 兼容性与边界

- 仅影响 `J`；`I 鞋眼片` 和其它 `mask_tint` 部件继续使用官方皮料库。
- 不新增图片资源，不改变鞋带 mask、视角、图层顺序或确认单结构。
- 已存在但不符合新约束的 `J` 配置，在初始化/渲染时回退到默认白色固定选项，避免产生不可渲染状态。

## 验证

- 运行固定材质/schema 契约测试，确认 `J` 只暴露 5 个色值且其它部件契约不变。
- 运行与材质选择相关的现有 UI 测试，确认点击 5 个颜色后鞋带颜色更新，并确认其它官方皮料仍可选。
- 检查 `git diff --check`，确认本次修改没有空白错误。
